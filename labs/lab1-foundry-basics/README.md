# Lab 1: Microsoft Foundry でエージェントを作る

> Microsoft Foundry ポータル上で、GUI だけを使って最初のエージェントを 1 体作成します。モデルの選択、Instructions の設計、プレイグラウンドでの対話テストまでを扱います。

セットアップ・演習の流れは [ルート README](../../README.md) を参照してください。

---

> ⚠️ **本 Lab はコードを書きません**: すべて Microsoft Foundry ポータルの GUI 操作で完結します。

## 🎯 このパートのゴール

- Microsoft Foundry のプロジェクトとエージェントの関係を理解する
- ポータル上で **エージェントを 1 体作成する**
- モデルを差し替えて、応答の違いを体感する
- **Instructions** を書いて、エージェントの振る舞いを制御する
- ナレッジを持たないエージェントの限界を確認する

## 📋 前提条件

| 項目 | 要件 | 確認方法 |
|------|------|---------|
| ブラウザ | Microsoft Edge または Google Chrome | 最新版を推奨 |
| Azure アカウント | 当日配布するアカウントでサインイン済み | ポータル右上のアイコン |
| Foundry プロジェクト | 事前に払い出し済み | 演習 0.1 で確認 |
| モデルデプロイ | `gpt-5.4-mini` / `gpt-5.6-sol` が配置済み | 演習 0.2 で確認 |

> 💡 **環境は準備済みです**: Foundry リソース、プロジェクト、モデルデプロイ、権限設定はすべて事前に完了しています。参加者の皆さんが Azure リソースを作成する必要はありません。

## 🎬 ワークショップのシナリオ

架空の日用消費財メーカー **サンライト株式会社** の「お客様相談室」を題材にします。

| 項目 | 内容 |
|------|------|
| 企業 | サンライト株式会社（架空の日用消費財メーカー） |
| 部門 | お客様相談室 |
| 課題 | 問い合わせの一次対応に時間がかかり、担当者によって回答の質がばらつく |
| 扱う製品 | 衣料用液体洗剤「アクアクリア」／食器用洗剤「キュットフォーム」／ヘアケア「モイストヴェール」 |
| 本 Lab で作るもの | 一次対応を支援するエージェント「相談室アシスタント v1」 |

> 💡 **すべて架空です**: 本ワークショップで使用する企業名・製品名・文書・データは、研修のために作成した架空のものです。実在の企業・製品とは一切関係ありません。

## 演習 0: 環境を確認する (5min)

ハンズオンを始める前に、配布された環境が正しく見えているかを確認します。

### 0.1 Foundry ポータルにサインインする

#### 手順

1. ブラウザで [Microsoft Foundry ポータル](https://ai.azure.com/) を開く
2. 当日配布したアカウントでサインインする
3. 画面左上の **プロジェクト セレクター** をクリックし、配布されたプロジェクト（例: `sunlight-support`）を選択する

**✅ 成功確認:**
- 画面左のナビゲーションに **「エージェント」**「モデル + エンドポイント」「プレイグラウンド」が表示される
- 画面上部にプロジェクト名が表示されている

> ⚠️ **プロジェクトが見つからない場合**: 画面右上のアカウント名をクリックし、サインインしているアカウントが配布したものと一致しているか確認してください。個人アカウントや普段の業務アカウントでサインインしていると、プロジェクトは表示されません。

### 0.2 デプロイ済みモデルを確認する

#### 手順

1. 左ナビゲーションの **「モデル + エンドポイント」** をクリック
2. **「モデル デプロイ」** タブを開く

**✅ 成功確認:**

以下の 2 つのデプロイが一覧に表示されていること。

| デプロイ名 | モデル | 用途 |
|------|------|---------|
| `gpt-5.4-mini` | GPT-5.4 mini | 演習 1 で最初に使う安価なモデル |
| `gpt-5.6-sol` | GPT-5.6 sol | 演習 1.3 で比較する高性能モデル |

> 💡 **モデルの読み方**: `mini` が付くモデルは、応答が速く安価な代わりに、複雑な推論はやや苦手です。用途に応じて使い分けます。この「差」は演習 1.3 で実際に体感します。

## 演習 1: エージェントを作成する (25min)

> ❗ **前提**: 演習 0 が完了していること。

この演習では、ナレッジをまだ持たない「素の」エージェントを 1 体作成します。

### 1.1 エージェントを新規作成する

#### 手順

1. 左ナビゲーションの **「エージェント」** をクリック
2. **「+ 新しいエージェント」** (New agent) をクリック
3. エージェントが 1 体作成され、右側に設定パネルが開く
4. **「エージェント名」** (Agent name) を次のように変更する

```
相談室アシスタント v1
```

5. **「デプロイ」** (Deployment) のプルダウンから `gpt-5.4-mini` を選択する

**✅ 成功確認:**
- エージェント一覧に「相談室アシスタント v1」が表示される
- 設定パネルに **エージェント ID**（`asst_` で始まる文字列）が表示される

> 💡 **エージェント ID は自動採番されます**: `asst_xxxxxxxx` の形式で、後からコードで呼び出すときに使います。今は控える必要はありません。

### 1.2 何も設定せずに話しかけてみる

Instructions を書く前に、素の状態でどう応答するかを見ておきます。後で「書いた場合」と比較するための基準にします。

#### 手順

1. 設定パネル右上の **「プレイグラウンドで試す」** (Try in playground) をクリック
2. 画面下部の入力欄に、次の質問を入力して送信する

```
アクアクリアは、ドラム式洗濯機でも使えますか？
```

**✅ 期待される挙動:**

```
（それらしい一般論が返ってくる。ただし「アクアクリア」という
  製品を知らないため、具体的な根拠は示されない）
```

> ⚠️ **ここが重要です**: エージェントは知らないことでも、それらしく答えてしまうことがあります。この時点では「何を根拠に答えているか」が一切分かりません。この状態を覚えておいてください。

### 1.3 モデルを差し替えて違いを見る

#### 手順

1. プレイグラウンド左上（またはエージェント設定パネル）の **「デプロイ」** を `gpt-5.6-sol` に変更する
2. **同じ質問** をもう一度送信する

```
アクアクリアは、ドラム式洗濯機でも使えますか？
```

3. 応答の長さ・丁寧さ・断定の強さを、先ほどと比べる

**✅ 成功確認:**
- 同じ質問に対して、応答の粒度や言い回しが変わることを確認できる
- 応答が返ってくるまでの時間にも差があることに気づく

> 💡 **どちらが「正解」ではありません**: 一次対応のように短く正確な応答が欲しい場面では `mini` で十分なことが多く、複雑な判断を挟む場面では上位モデルが向きます。**用途に応じて選び、後から差し替えられる**ことが Foundry の利点です。

確認が終わったら、**デプロイを `gpt-5.4-mini` に戻して**ください。以降の演習はこちらで進めます。

### 1.4 Instructions を書く

エージェントの振る舞いを決める、最も重要な設定です。

#### 手順

1. エージェント設定パネルの **「手順」** (Instructions) 欄を開く
2. 次の内容を **そのまま貼り付ける**

```text
あなたはサンライト株式会社 お客様相談室の一次対応担当です。
お客様からのお問い合わせに、正確かつ簡潔にお答えしてください。

【回答のルール】
- 回答は3行以内にまとめてください。
- 回答の最後に、参照した資料名を必ず書いてください。
- ナレッジに根拠がない場合は推測せず、担当者へのエスカレーションを案内してください。

【禁止事項】
- 医薬品的な効能効果の表現（「治る」「効く」など）は使わないでください。
- 「絶対に安全」「副作用は一切ない」などの断定的な表現は使わないでください。
- 他社製品との比較や論評はしないでください。
```

3. パネル上部の **「保存」** をクリック（自動保存される場合もあります）

**✅ 成功確認:**
- Instructions 欄に貼り付けた内容が保持されている
- エージェント一覧に戻っても内容が消えていない

**ポイント解説:**

- **役割の宣言** — 「あなたは〜です」で立場を固定します。これがないと、汎用アシスタントとして振る舞います
- **出力フォーマットの指定** — 「3行以内」「資料名を書く」のように、形式を数値で指定すると安定します
- **知らないときの振る舞い** — 一次対応では、これが最も重要です。推測で答えさせないための一文です
- **禁止事項** — 消費財メーカーでは薬機法の観点から必須です。Instructions で最初のガードレールを張ります

### 1.5 Instructions の効果を確認する

#### 手順

1. プレイグラウンドで、次の 3 つの質問を順に送信する

```
アクアクリアは、ドラム式洗濯機でも使えますか？
```

```
アクアクリアを使うと、手荒れは治りますか？
```

```
アクアクリアの2027年春の新製品の発売日を教えてください。
```

**✅ 期待される挙動:**

| # | 質問 | 期待される応答 |
|------|------|---------|
| 1 | ドラム式で使えるか | 演習 1.2 より短く、形式が整った応答になる |
| 2 | 手荒れは治るか | 「治る」といった表現を避け、医薬品的な断定をしない |
| 3 | 新製品の発売日 | 推測せず、担当者へのエスカレーションを案内する |

> 💡 **まだ完璧ではありません**: 1 の質問には、相変わらず「根拠となる資料名」を書けないはずです。ナレッジを持っていないからです。この続きは **Lab 2** で解消します。

### 1.6 Instructions を書き換えて挙動を変える（任意）

時間に余裕がある方は、Instructions を書き換えて振る舞いが変わることを確かめてください。

**試してみる例:**

- 「回答は3行以内」を **「回答は1行で」** に変える → 応答が極端に短くなる
- 「【禁止事項】」のブロックを **一時的に削除する** → 2 の質問への応答が変わる（確認後は必ず元に戻してください）
- 末尾に **「語尾は必ず『〜でございます』にしてください。」** を足す → 口調が変わる

> ⚠️ **確認が終わったら、演習 1.4 の Instructions に戻してください。** Lab 2 はこの状態から続きます。

## 📝 まとめ

| やったこと | 使った機能 |
|------|------|
| プロジェクトとモデルデプロイを確認した | モデル + エンドポイント |
| エージェントを 1 体作成した | エージェント |

**この Lab で分かったこと:**

- エージェントの振る舞いは、**Instructions の書き方でほぼ決まる**
- ただし Instructions だけでは、**社内固有の事実には答えられない**

## 🚨 トラブルシューティング

### プロジェクトが一覧に表示されない

**原因**: 別のアカウントでサインインしている、または別のテナントを見ている。

**解決方法**:
1. 画面右上のアカウントアイコンをクリックし、サインイン中のアカウントを確認する
2. 配布されたアカウントと異なる場合はサインアウトし、再度サインインする
3. ブラウザの **シークレット ウィンドウ / InPrivate ウィンドウ** を使うと、普段のアカウントと混ざらずに済みます

### エージェント作成時に「権限がありません」と表示される

**原因**: プロジェクトに対するロールが割り当てられていない。

**解決方法**: 講師またはサポーターにお声がけください。**Azure AI User** 相当のロールを付与します。参加者側での対処は不要です。

### プレイグラウンドで応答が返ってこない

**原因**: モデルデプロイが選択されていない、またはレート制限に達している。

**解決方法**:
1. エージェント設定パネルで **「デプロイ」** が選択されているか確認する
2. 数十秒待ってから再送信する（同時に多数が実行するとレート制限がかかることがあります）
3. `gpt-5.6-sol` を使っている場合は `gpt-5.4-mini` に切り替えて再試行する

### Instructions を保存しても反映されない

**原因**: 保存前にプレイグラウンドへ遷移した、またはブラウザのセッションが切れている。

**解決方法**:
1. エージェント設定パネルに戻り、Instructions 欄の内容を確認する
2. 内容が消えている場合は貼り直し、**「保存」** を押してからプレイグラウンドを開く
3. それでも反映されない場合は、ブラウザを再読み込み（F5）してから再度貼り付ける

### 応答が英語で返ってくる

**原因**: Instructions に言語の指定がないため、質問内容によっては英語で応答することがあります。

**解決方法**: Instructions の冒頭に次の 1 行を追加してください。

```text
回答は必ず日本語で行ってください。
```
